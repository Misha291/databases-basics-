# 📘 SQL — основные команды и понятия (для новичка)

---

## 🧱 1. Создание и изменение структуры таблиц

| Команда          | Простое объяснение                   |
| ---------------- | ------------------------------------ |
| `CREATE TABLE`   | Создать новую таблицу                |
| `DROP TABLE`     | Удалить таблицу полностью            |
| `ALTER TABLE`    | Изменить структуру таблицы           |
| `ADD COLUMN`     | Добавить новый столбец               |
| `DROP COLUMN`    | Удалить столбец                      |
| `RENAME COLUMN`  | Переименовать столбец                |
| `TRUNCATE TABLE` | Очистить таблицу (быстро, без WHERE) |

---

## 🧩 2. Типы данных (что можно хранить)

| Тип            | Что это                    |
| -------------- | -------------------------- |
| `INT`          | Целое число                |
| `SERIAL`       | Авто-номер (1, 2, 3…)      |
| `IDENTITY`     | Современный авто-номер     |
| `VARCHAR(n)`   | Текст до `n` символов      |
| `TEXT`         | Текст без ограничения      |
| `NUMERIC(p,s)` | Число с точностью (деньги) |
| `BOOLEAN`      | `true` / `false`           |
| `DATE`         | Дата                       |
| `TIMESTAMP`    | Дата + время               |

---

## 🔐 3. Ограничения (правила для данных)

| Ограничение   | Понятно по-человечески                  |
| ------------- | --------------------------------------- |
| `PRIMARY KEY` | Главный уникальный идентификатор строки |
| `FOREIGN KEY` | Ссылка на другую таблицу                |
| `NOT NULL`    | Поле обязательно                        |
| `UNIQUE`      | Значение не повторяется                 |
| `CHECK`       | Проверка условия                        |
| `DEFAULT`     | Значение по умолчанию                   |
| `CONSTRAINT`  | Имя для правила                         |

📌 `PRIMARY KEY` = `NOT NULL` + `UNIQUE` автоматически

---

## 🧮 4. Работа с данными (CRUD)

### ➕ Добавление данных

| Команда       | Что делает               |
| ------------- | ------------------------ |
| `INSERT INTO` | Добавить строку          |
| `VALUES`      | Указать значения полей   |

```sql
INSERT INTO products (name, price)
VALUES ('Телефон', 199.99);

```

---

### 👀 Чтение данных

| Команда    | Что делает            |
| ---------- | --------------------- |
| `SELECT`   | Получить данные       |
| `FROM`     | Из какой таблицы      |
| `WHERE`    | Условие               |
| `ORDER BY` | Сортировка            |
| `LIMIT`    | Ограничить количество |
| `DISTINCT` | Убрать повторы        |

```sql
SELECT name, price
FROM products
WHERE price > 100
ORDER BY price;
```

---

### ✏️ Изменение данных

| Команда  | Что делает      |
| -------- | --------------- |
| `UPDATE` | Изменить данные |
| `SET`    | Что изменить    |
| `WHERE`  | К каким строкам |

```sql
UPDATE products
SET price = 150
WHERE product_id = 1;
```

---

### ❌ Удаление данных

| Команда  | Что делает     |
| -------- | -------------- |
| `DELETE` | Удалить строки |
| `WHERE`  | Какие строки   |

```sql
DELETE FROM products
WHERE price < 10;
```

---

## 🛠️ 5. Изменение правил и структуры (ALTER)

| Команда                | Значение                   |
| ---------------------- | -------------------------- |
| `ALTER TABLE ... ADD`  | Добавить столбец / правило |
| `ALTER TABLE ... DROP` | Удалить столбец / правило  |
| `DROP CONSTRAINT`      | Удалить ограничение        |
| `ADD CONSTRAINT`       | Добавить ограничение       |

```sql
ALTER TABLE products
ADD CONSTRAINT price_check CHECK (price > 0);
```

---

## 🔗 6. Связи между таблицами

| Команда       | Объяснение               |
| ------------- | ------------------------ |
| `FOREIGN KEY` | Связывает таблицы        |
| `REFERENCES`  | Указывает, на что ссылка |

```sql
FOREIGN KEY (product_id)
REFERENCES products(product_id)
```

👉 «Этот `product_id` обязан существовать в `products`»

---

## 🧠 7. Полезные логические операторы

| Оператор  | Значение    |
| --------- | ----------- |
| `AND`     | И           |
| `OR`      | Или         |
| `IN`      | В списке    |
| `BETWEEN` | В диапазоне |
| `LIKE`    | По шаблону  |
| `IS NULL` | Пусто       |

---

## 🧾 8. Агрегатные функции (подсчёты)

| Функция    | Что считает |
| ---------- | ----------- |
| `COUNT()`  | Количество  |
| `SUM()`    | Сумму       |
| `AVG()`    | Среднее     |
| `MIN()`    | Минимум     |
| `MAX()`    | Максимум    |
| `GROUP BY` | Группировка |

---

## 🟢 Финальное резюме (самое важное)

- **Структура**: `CREATE / ALTER`
- **Данные**: `INSERT / SELECT / UPDATE / DELETE`
- **Правила**: `PRIMARY KEY / FOREIGN KEY / CHECK`
- **Чтение**: `SELECT + WHERE`
- **Без WHERE — опасно** ⚠️
